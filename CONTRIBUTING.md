# Contributing

Thanks for your interest in Forge.

## Issues are welcome

Found a bug or have an idea? [Open an issue](https://github.com/rameezk/forge/issues/new/choose) using the bug report or idea form. Clear reports and well-described problems are the most useful contribution you can make.

## Pull requests are not accepted

Forge does not take outside pull requests, and only collaborators can open them. Work enters Forge as tickets that are refined first and then built by Forge's own agents and proved through CI. A ticket labelled `ready-for-refinement` is not settled yet, so a change against it would be guessing at its scope. If you have a fix in mind, describe it in an issue instead. The reasons are recorded in [ADR-0113](docs/adr/0113-forge-does-not-take-outside-pull-requests.md).

## Security

Report vulnerabilities privately, as described in [SECURITY.md](SECURITY.md), never in a public issue.
